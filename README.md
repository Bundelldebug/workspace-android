# 워크스페이스 (Workspace Android) — 9.5.1

문서(DOCX/HWP/HWPX), 스프레드시트(XLSX/CSV), 프레젠테이션(PPTX)을 편집하는 One UI 9.5 리퀴드 글래스 오피스 앱입니다.

## 주요 기능
- 워드·시트·슬라이드 편집 및 내장 오피스 코덱(`.docx`, `.xlsx`, `.pptx`, `.hwp`, `.hwpx`, `.odt`, `.ods`, `.odp`, `.csv`, `.txt`)
- 기본 앱(`ACTION_VIEW`) 등록으로 파일 관리자에서 바로 열기
- 폰 전용 하단 플로팅 리퀴드 글래스 내비게이션 & 바텀 시트 UI / 폴더블·태블릿 데스크탑급 레이아웃
- GitHub Releases 앱 내 업데이트

## 빌드

powershell -ExecutionPolicy Bypass -File build.ps1
